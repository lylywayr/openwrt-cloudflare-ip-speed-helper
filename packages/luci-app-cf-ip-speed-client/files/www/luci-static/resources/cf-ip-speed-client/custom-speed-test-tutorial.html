如何创建自定义测速地址

优选需要一个可持续下载的 HTTPS 地址来测量实际速度。测速接口格式为 /__down?bytes=10485760，其中 bytes 是下载字节数。

一键创建（推荐）

  1. 在基本设置 → 自定义测速地址中，确认已在结果部署 → Cloudflare Pages保存 Cloudflare 账户邮箱和 Global API Key。
  2. 勾选“我同意创建测速 Worker”。未授权、凭据无效或未保存时，勾选会自动取消并提示原因。
  3. 选择地址方式：
    • 自动 workers.dev 地址：不需要填写域名。
    • 自己的 Cloudflare 域名：填写已托管到 Cloudflare 的顶级域名与二级域名前缀，例如 speed + example.com。
  4. 点击自动创建测速地址。进度区域会实时显示上传、绑定和验证状态。
  5. 完成后，地址会自动填回“自定义测速地址”输入框，并立即持久化保存。

手动填写

也可以填写已存在的地址，例如：

https://speed.example.com/__down

保存前可先访问 https://speed.example.com/__down?bytes=1024，确认能正常下载。

注意事项

使用自定义域名时，系统会创建一个代理 DNS 记录，并将 二级域名.顶级域名/* 绑定到测速 Worker。该域名必须已由 Cloudflare 托管。
  • 不要使用跳转、需要登录、有缓存或限流的下载链接。
  • 测速 Worker 名默认为 cf-speed-test，可自行修改以避免与已有 Worker 冲突。
  • 创建过程不会显示、导出或写入 Cloudflare 密钥到日志。
